SATB Harmony Grader and Solver

The same Python engine as the source on GitHub, running entirely in your browser: nothing is sent to a server. The first load takes a few seconds.

  1. A progression in C major is loaded, with only Roman numerals and a final cadence. Click Solve to realize all four voices.
  2. Click Voice Grader to check the result against eleven categories of part-writing rules. Select a note and move it with the arrow keys, then grade again to see what breaks.
  3. To write your own: pick a voice (S, A, T, B), click on the staff to place notes, type a Roman numeral under each bar, and add a cadence label (PAC, IAC, HC) where a phrase ends.

This tool is built for a computer screen; on a phone the score is cramped.
